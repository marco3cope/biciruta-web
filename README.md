# BiciRuta Web

Página web de BiciRuta S.L., tienda de bicicletas. Proyecto de la UT1 del módulo 0373 Lenguajes de marcas.

## Estructura

```
biciruta-web/
├── index.html
├── css/estilos.css
├── js/app.js
├── img/logo_biciruta.png
├── README.md
└── .gitignore
```

## Cómo verlo

1. Abre la carpeta en VS Code.
2. Instala la extensión Live Server.
3. Clic derecho sobre `index.html` → Open with Live Server.
